zBay on Discord

Announce your server's sales and auctions in a channel, let players search the market from Discord, and message them when they're outbid. About ten minutes, and you need to be able to run a program on the machine your game server runs on.

  1. Add the bot to your Discord server

    It asks for two things: to see channels and to send messages. It never reads what anybody types.

    Add to Discord

    This page hasn't been given the bot's id yet, so the button is off.

  2. Get your server key

    In your Discord server, run /zbay setup. You need the Manage Server permission. The bot replies, to you only, with a key that starts zb_.

    The key is shown once. It is what lets a game server speak for your Discord server, so treat it like a password. If it ever gets out, /zbay setup new_key:True replaces it and the old one stops working.

  3. Start your game server once with zBay installed

    The mod writes its settings the first time the world starts. Afterwards there is a folder called zBay inside your server's Zomboid/Lua folder, with config.json and discord.json in it.

    On a host that gives the server its own data folder, look there instead, for example server-data/Lua/zBay.

  4. Fill in discord.json

    Paste your key and pick what gets announced. The file is built in your browser: the key is not sent anywhere, this page included.

  5. 
      
    Run the relay beside your game server
    
      
    The game can't reach the internet from a mod, so a small program carries messages between the zBay folder and the bot. It is one Python file with nothing to install, and it needs Python 3.9 or newer.
    
      
    Download zbay_relay.py
    
      
    Run it with the path to that same zBay folder:
    
      
    python zbay_relay.py --zbay-dir "C:\Users\you\Zomboid\Lua\zBay"
    
      
    Leave it running for as long as the server is. If it stops, nothing is lost: it picks up where it left off, and the game carries on without it.
    
      
    Optional: add --rcon-port with your server's RCON port, and set ZBAY_RCON_PASSWORD in the environment, to have commands from Discord acted on at once instead of within a few seconds.

  6. 
      
    Pick a channel, and tell your players
    
      
    
        
    /zbay channelWhere sales and auctions are announced. Admins only.
    
        
    /zbay searchSearch what's for sale.
    
        
    /zbay listingsThe newest fixed-price listings.
    
        
    /zbay auctionsAuctions running now.
    
        
    /zbay linkGives a player a code to type into the Bank tab in game. Once linked, they get a message when they're outbid, when something of theirs sells, and when mail is waiting.
    
        
    /zbay balanceWhat's in a linked player's bank.
    
        
    /zbay unlinkStops the messages.
